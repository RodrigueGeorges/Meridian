    Ne perdez plus une vente à cause du PSP du marchand.

    Chaque marchand arrive avec son PSP. Chaque PSP coûte une intégration, une certification et de la maintenance. Avec Meridian, vous intégrez une fois et proposez tout le catalogue.

    Cinq appels. Pas un de plus.

const m = new Meridian({ apiKey, posId });

    Un module déclaratif, pas un projet.

    Vous décrivez votre API dans un fichier : étapes, clés d'idempotence, lecture d'état, codes de refus. Aucun code dans le moteur. Le module est refusé s'il ne garantit pas l'idempotence.

    {
  "id": "votre-psp",
  "countries": ["FR", "BE", "DE"],
  "pay": [
    { "id": "create", "method": "POST", "path": "/payments",
      "idempotency": "{reference}:create" }
  ],
  "lookup": { "path": "/payments/{vars.id}" },
  "declineCodes": ["card_declined"]
}
