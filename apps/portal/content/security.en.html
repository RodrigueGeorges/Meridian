Meridian sits between the till and the PSP. Here is what we see, what we keep, and how you can check it.

What never goes through Meridian

  • No full card number. The card is read by the PSP’s terminal. Meridian only receives what the PSP returns on the receipt: the brand and the last four digits.
  • No funds. Money flows from the PSP to the merchant. Meridian is not a payment institution and holds no safeguarding account.
  • No opaque automated decisions. No AI model is involved in processing a payment.

A payment is never lost or charged twice

  • Each step is written to the journal before the PSP is called.
  • Each step carries an idempotency key: a replayed call does not create a second charge.
  • A network error yields “in progress”, never “failed”: Meridian queries the PSP for the real outcome.
  • Failover to a backup PSP only happens when the connection is refused before anything is sent.
  • If an instance goes down mid-payment, another one resumes the payment where it stopped.

These rules are checked on every release: 8 failure scenarios and 200 random failure sequences, where the only pass criterion is a single charge.

A journal you can prove

Each journal entry is chained to the previous one with a SHA-256 hash and signed with HMAC. In the database the journal is append-only: changing an existing entry is refused. Chain integrity can be checked at any time through the API (GET /v1/journal/verify).

Secrets and access

  • Merchants’ PSP credentials are encrypted at rest (AES-256-GCM).
  • API keys are only stored as hashes; test and live keys are separate.
  • Webhooks are signed (HMAC-SHA256 with a timestamp) so you can verify where they come from.
  • Traffic is encrypted (HTTPS, HSTS) and the site enforces a strict content security policy.

What we don’t have yet

Meridian does not hold PCI DSS or ISO 27001 certification today. Because Meridian handles no full card number its PCI DSS scope is reduced; the exact level will be confirmed by a qualified assessor. We will list each certification on this page once obtained, never before.
